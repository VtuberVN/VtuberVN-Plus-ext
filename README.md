# VtuberVN Star v1 (Lite Edition)

Phiên bản rút gọn siêu nhẹ của tiện ích mở rộng [VtuberVN](https://vtuberhub.vn), tập trung vào hiển thị Live Chat kính mờ và nút chuyển nhanh YouTube.

---

## 🌟 Tính Năng Chính

- **Khung Live Chat Kính Mờ (Glassmorphic Chat)**: Mở khung chat trực tiếp và xem lại chat của stream đã kết thúc trên VtuberVN.
- **Nút Chuyển Nhanh trên YouTube**: Gắn nút "Xem trên VtuberVN" bên dưới video YouTube.
- **Không Cần Quyền Riêng Tư Đặc Biệt**: Không yêu cầu quyền truy cập cookie tài khoản hay quản lý phiên đăng nhập YouTube.
- **Siêu Nhẹ & Tối Giản**: Tải nhanh, tiêu tốn cực ít tài nguyên RAM/CPU.

---

## 🚀 Hướng Dẫn Cài Đặt

### 1. Chrome / Edge / Brave / Cốc Cốc
1. Mở `chrome://extensions/` &rarr; bật **Developer mode**.
2. Kéo thả file `vtubervn-plus-v1-v1.1.3.crx` hoặc giải nén `vtubervn-plus-v1-v1.1.3-chrome.zip` và bấm **Load unpacked**.

### 2. Firefox
1. Mở `about:addons` &rarr; chọn biểu tượng bánh răng ⚙️ &rarr; **Install Add-on From File...**.
2. Chọn file `vtubervn-plus-v1-v1.1.3.xpi`.

---

## 💻 Lệnh Phát Triển & Đóng Gói

```bash
# Cài đặt
yarn install

# Chạy thử nghiệm
yarn dev:chrome
yarn dev:firefox

# Đóng gói bản Production
yarn pack
```
